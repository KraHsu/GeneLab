                                                                                                    
 Usage: genelab [OPTIONS] COMMAND [ARGS]...                                                         
                                                                                                    
 GeneLab — Genesis robot lab CLI.                                                                   
                                                                                                    
 Run `genelab` with no arguments for a landing page with quickstart commands and a count of         
 registered robots, envs, and tasks.                                                                
                                                                                                    
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --version                           Show version and exit.                                       │
│ --import                    MODULE  Import an extension module before dispatch (repeatable).     │
│ --no-entry-points                   Skip installed entry points from the genelab.extensions      │
│                                     group.                                                       │
│ --install-completion                Install completion for the current shell.                    │
│ --show-completion                   Show completion for the current shell, to copy it or         │
│                                     customize the installation.                                  │
│ --help                              Show this message and exit.                                  │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Utilities ──────────────────────────────────────────────────────────────────────────────────────╮

╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Registry ───────────────────────────────────────────────────────────────────────────────────────╮
