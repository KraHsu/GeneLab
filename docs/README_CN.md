# GeneLab

中文 | [EN](../README.md)

GeneLab 是一个面向强化学习与机器人研究的 Isaac Lab 风格 API，由
[Genesis](https://github.com/Genesis-Embodied-AI/Genesis) 提供仿真后端。注册机器人、环境、
任务，manager-based MDP 配置，以及 CLI 调度等组织方式与上游保持一致。

- 完整文档（中文）：<https://krahsu.github.io/GeneLab/zh/>。
- 示例与下游项目集成：[`examples/`](../examples/README.md)。

本文件仅作为仓库根目录的中文入口与跳转占位，详细安装、CLI 参考、核心概念、API 自动参考请前往
上方文档站点。
